# 仁维脚本生成系统

本仓库记录仁维短视频驾驶舱合作协议中**文本策划工作流**的实现与验收进度，并跟踪与之相连的剪辑、数据复盘交付。当前代码是 2026-10-03 从 193 服务器筛选的运行文件快照，依赖 Crabot、飞书通道、上游视频服务及服务器配置；**不能直接作为独立应用部署**。

## 项目范围

合同本期包含三个分别验收的模块：文本策划、自动化剪辑、两个指定账号的数据复盘。文本模块须走三轮完整流程，第三轮交付调研、账号定位与策划、分镜脚本、拍摄实施计划。剪辑模块须交付两个账号均可导入、编辑、保存并重开的剪映工程。复盘模块须对两个账号分别提供来源可追溯的数据和改进建议。详见 [交付范围](docs/contract-scope.md)。

## 当前状态

截至 2026-10-03，资料索引、事实与素材库、对标逻辑、脚本规则、视频声画证据和部分账号作品索引已有实现及测试。**三个合同模块均未在本仓库记录为最终验收通过**。尤其尚无可核验的两个账号剪映工程和双账号完整数据复盘证据。详见 [进度与缺口](docs/status-2026-10-03.md)。

## 仓库结构

- `runtime/skills/`：线上技能规则与素材准备脚本快照。
- `runtime/tools/`：受限来源索引、视频分析、时间轴和账号作品工具快照。
- `runtime/patches/`：模型适配器、重试和超时补丁快照。
- `docs/`：合同范围、进度、证据及排期。
- `templates/`：驻场问题与复验记录模板。

原合同、客户附件、视频、账号数据、聊天记录、凭据、服务器配置和付款信息不上传。合同文件目前标注为草案，签章及附件一部分实施参数仍待双方确认。本仓库的状态记录不代替小鹿的书面验收。
